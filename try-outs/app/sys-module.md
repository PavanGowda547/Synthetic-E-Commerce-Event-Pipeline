## Sys Module

It is a built-in python module that lets your python program interact with the python runtime and the operating system environment. it is mainly useful for controlling and monitoring how a pipeline or ETL program runs.

The list of things it can do is :
- passing information to a pipeline
- telling the system whether the job succeeded
- receiving data from another process
- sending normal output
- sending error information
- controlling where Python looks for modules
- finding which Python is running
- finding the Python version
- checking Python version information
- identifying the operating system
- seeing what Python modules are loaded
- checking object size
- handling unexpected errors
- checking recursion limits
- changing the recursion limit

To learn more on this module refer `sys-module.py` file
